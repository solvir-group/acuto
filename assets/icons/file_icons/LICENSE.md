# File icon licences

Most of the language and tooling icons in this directory are from
[Simple Icons](https://github.com/simple-icons/simple-icons), released under
**CC0 1.0 Universal** (public domain dedication). No attribution is required;
this note records the provenance rather than discharging an obligation.

They were chosen because they are the brand marks themselves rather than
approximations of them, and because each is a single monochrome path — which is
what this editor's renderer needs, since it tints every icon with one colour
drawn from the active theme.

Brand marks remain the trademarks of their respective owners. CC0 covers the
icon artwork, not the right to use a company's mark to imply endorsement.

The remaining icons — folders, chevrons, and generic glyphs for documents,
images, archives and settings — are Zed's own, under the licence at the root of
this repository.
