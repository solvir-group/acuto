## Windows correctness

Implement IME. `WM_IME_STARTCOMPOSITION` / `WM_IME_COMPOSITION` / `WM_IME_ENDCOMPOSITION`. Candidate window follows the caret. Composition string renders inline with underline, not as committed text. Works in the buffer, the terminal, and every UI text input.

Add `longPathAware` to the manifest and audit every `PathBuf` → win32 call for the `\\?\` prefix. Support UNC paths, falling back to polling for file watching over SMB with a UI indicator. Don't block the UI thread reading OneDrive placeholder files. Don't show duplicate file tree entries for `Foo.rs` and `foo.rs`.

Detect CRLF/LF on open, preserve on save, never silently convert. Honour `.gitattributes` `eol` and `text`. Show the current line ending in the status bar, click to change. Detect mixed line endings and warn.

Integrate Git Credential Manager by shelling out to `git` and letting GCM prompt. Handle `core.autocrlf` in the diff view so CRLF doesn't show every line as changed.

Use ConPTY, not winpty, with graceful degradation below build 1809. Handle `cmd.exe`, `powershell.exe` 5.1, `pwsh.exe` 7+, Git Bash, and WSL as four different things with different quoting and startup files. Ctrl+C interrupts the child, doesn't kill the terminal.

## Shell integration

Delete `command_suggest.rs` first.

Fork alacritty into `crates/vendored/`. Parse `OSC 133;A/B/C/D`, `OSC 633;E` for command text, `OSC 633;P;Cwd`, and `OSC 7` as fallback. Emit a typed `ShellEvent` stream. The terminal grid and block model both consume it; the block model never re-parses the grid.

Inject per-process, never touching the user's rc files:

- zsh: `ZDOTDIR` to a temp dir whose `.zshrc` sources the real one then appends hooks
- bash: `--init-file` shim that sources `~/.bashrc`
- fish: `XDG_DATA_DIRS` with a `vendor_conf.d` entry
- pwsh 7+: `-NoExit -Command`, dot-source a generated shim, then load `$PROFILE`. Hook the `prompt` function and PSReadLine's `OnCommandLineAccepted`. Read both `$LASTEXITCODE` and `$?` since they disagree. Wrap custom prompts (oh-my-posh, starship) rather than replacing them.
- powershell 5.1: same, but PSReadLine may be absent. Degrade to prompt-hook-only.
- cmd.exe: `PROMPT` with `$E` escapes. Prompt boundaries and exit code only, no command text.
- WSL: pass injection env vars through `WSLENV`.

If injection fails the terminal still works as a plain terminal. Show whether integration is active. Allow disabling per shell.

## Terminal blocks

Build a `Block`: command text, cwd, start time, duration, exit code, output range, fold state. Construct from the `ShellEvent` stream. Cap retained output per block, spill to disk past the limit.

Fold and unfold output. `Ctrl+Up` / `Ctrl+Down` jump between blocks. Non-zero exits get a scrollbar gutter marker plus jump-to-next-failure. A filter view showing only failures. Click to rerun, shift-click to rerun with the command loaded for editing. Copy command, output, or both. Show duration on anything over 2 seconds.

Click a failed block to get a fix as a diff, not a chat message. Send command, exit code, output tail, cwd, and relevant file contents to the configured LLM. Constrain the response to a patch. Render in the hunk-review UI. Nothing hits disk until accepted.

Persist blocks per workspace across sessions. Semantic search over block history. Denylist blocks containing secrets — match common env var names and token shapes.

## Agent workflow

Agent edits land in a git worktree created with `git worktree add` on the same volume, never in the user's files. User reviews the diff between shadow and working tree. Accept applies to the real tree, reject deletes the worktree. Handle dirty trees and untracked files without data loss.

Finish per-hunk accept/reject correctness. File the circular oracle bug in upstream `test_random_diffs` and work around it locally with a note in `UPSTREAM_ISSUES.md`. Keyboard-only review: next, previous, accept, reject, accept-all-in-file, undo. Sub-hunk selection. A 200-line change should be reviewable in under a minute without the mouse.

Run two agents on one task in two worktrees. Diff their outputs against each other, not just against HEAD. Cherry-pick hunks from either.

On save, run `cargo check -j 2` against the shadow copy and surface errors before they're asked for. Debounce hard and cancel on further edits.

Write a content-addressed snapshot of the working tree delta on every save, independent of git. Scrub a timeline slider over the last N hours. Restore a single file or the whole tree. Prune on a size budget.

## Enterprise

Portable mode: a marker file beside the exe puts config, cache, extensions, and logs in that folder. No registry writes, no `%APPDATA%`, no admin.

Respect `HTTP_PROXY` / `HTTPS_PROXY` / `NO_PROXY`, read the system proxy config including PAC files, support NTLM and Kerberos proxy auth. Read CA certificates from the Windows certificate store, not a bundled root list — corporate TLS inspection breaks bundled-roots clients completely. Everything except explicit network features works offline with no hangs.

Install extensions from a local file. Export the installed set as a bundle and import it on another machine.

Read policy from `HKLM\Software\Policies\Acuto`: disable updates, disable telemetry, pin the registry URL, force settings, disable AI. Ship an `.admx` template.

One-click open folder in WSL. Server component in the distro, editor on Windows. Path translation both ways. Terminal and shell integration work across the boundary.

Explorer right-click "Open with Acuto" on files and folders. Taskbar jump list of recent workspaces. Opt-in file associations during install.
